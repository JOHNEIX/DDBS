## 8.2 状态与接口约定

系统运行状态与事务状态分别维护。STARTING、RECOVERING、READY、BUSY、BLOCKED表示系统运行情况；STARTED、DECIDED_COMMIT、DECIDED_ABORT、DONE_COMMIT、DONE_ABORT表示全局事务进度。

普通查询目标站点离线时，该请求返回NODE_UNAVAILABLE，系统回到READY。写事务在STARTED之前检查目标站点；检查失败时返回请求错误。STARTED之后产生未决事务且无法收齐最终确认时，系统进入BLOCKED，恢复完成后回到READY。

集群status由协调器组合本地system_state与各站点PING结果。PING提供node_id、dataset_version与catalog_digest，可达性由调用结果生成。pending列出未决全局事务。

## 8.3 查询与恢复追踪

ROUTE记录目标站点与分片规则。LOCAL_JOIN记录参与表、返回行数和SQLite EXPLAIN QUERY PLAN的实际结果。RPC记录操作、站点及应用层报文字节数，字节数包含4字节长度前缀。

事务轨迹包含STARTED、PREPARED、全局决定、参与者状态及DONE事件。恢复轨迹通过RECOVER、PARTICIPANT、COMMITTED、ABORTED和BLOCKED展示处理进度。history按请求ID读取全局事件，trace.jsonl保留诊断明细。
